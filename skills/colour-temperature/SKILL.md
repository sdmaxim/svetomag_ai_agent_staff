# Light colour (colour temperature, in Kelvin)

| Kelvin | Name | Feels like | Good for |
|---|---|---|---|
| 2700 K | warm | cosy, like an old incandescent bulb | living room, bedroom, dining |
| 3000 K | warm white | warm but slightly fresher | living areas, hallways, halogen-like |
| 4000 K | neutral white | clear, natural | kitchen, bathroom, home office, shops |
| 5000-5500 K | daylight | bright, like daylight | work areas, reading, garages |
| 6000-6500 K | cold white | bluish, very bright | workshops, warehouses, technical use |

Codes on fluorescent and LED bulbs often hide the Kelvin: "827" = 2700 K, "830" = 3000 K, "840" = 4000 K, "865" = 6500 K (the last two digits x 100).

## How to search the catalogue
The `light_colour` filter uses these groups:
- `warm` = up to 3500 K
- `neutral` = 4000-4500 K
- `daylight` = 5000-5500 K
- `cold` = 6000 K and more

Examples: living room -> `light_colour="warm"`; kitchen worktop or bathroom mirror -> `light_colour="neutral"`; workshop -> `light_colour="daylight"` or `"cold"`.

## Be careful
- This is a matter of taste: recommend, but offer an alternative ("warm for cosiness, neutral if you want it brighter").
- Special lamps (for aquariums, plants, reptiles, solariums) have special spectra - only suggest them for that purpose.
- State a product's light colour only from its data; if it is not given, say it is not specified.
